# Technologies Then vs Now vs in the Future

An informative speech by **Atharva Kadam** (COM380 Public Speaking), built as a web slideshow.

**Topics:** agentic AI, robotics in construction, and 3D & 4D bioprinting.

## Presenting

Open the live site, press **F** for full screen, and click to move forward.

| Action | How |
| --- | --- |
| Next step or slide | Click anywhere, **→**, **Space**, **Page Down**, or a presentation clicker |
| Previous step or slide | **←**, **Page Up**, or the Back button |
| Full screen | **F** |
| Back to the first slide | **Home** |
| Jump to a slide | Add `#` and the slide number to the address, e.g. `.../#5` |
| Play the robotics video | Click the video itself |

The 4D bioprinting video starts by itself 2 seconds after its slide appears.

## Putting it on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload everything in this folder (`index.html`, `images/`, `videos/`, `.nojekyll`, `README.md`) to the root of the repository.
3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick **main** and **/ (root)**, then **Save**.
4. After a minute or two, the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Files

```
index.html          the slideshow
images/             photos used on the slides
videos/             each video in two formats (.webm and .mp4) so it plays in every browser
.nojekyll           tells GitHub Pages to serve the files as they are
```
